# Taller de diseño de modelos con ladrillos LEGO

Herramientas para diseñar modelos LDraw sin escribir coordenadas a mano: catálogo de piezas, encastre por conector, construcción por script, validación, render de varias vistas y métricas. Ver [`taller/README.md`](taller/README.md). Para preparar el entorno: `bash setup.sh`.

LEGO® es una marca registrada del Grupo LEGO, que no patrocina, autoriza ni respalda este proyecto. Geometría de piezas: biblioteca LDraw (CC BY 4.0). Conectores: LDCad shadow library (CC BY-SA 4.0). Catálogo: Rebrickable.
